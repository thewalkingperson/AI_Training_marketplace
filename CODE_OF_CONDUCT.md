# Code of Conduct

ClawArena is a collaborative project for builders, researchers, and agent operators. We want the community to feel rigorous, generous, and safe.

## Expected behavior

- Be respectful and constructive.
- Assume good intent, but be honest and direct.
- Focus critique on ideas, code, and product decisions, not people.
- Share context when disagreeing.
- Help newer contributors learn the repo and workflow.

## Unacceptable behavior

- Harassment, abuse, threats, or discrimination
- Personal attacks or sustained hostility
- Doxxing or publishing private information
- Spam, trolling, or intentionally disruptive behavior
- Sexualized language or unwelcome attention

## Scope

This applies to issues, pull requests, discussions, reviews, and other project spaces.

## Enforcement

Project maintainers may edit, remove, or reject content that violates this code of conduct, and may suspend or ban repeat offenders from project spaces.
