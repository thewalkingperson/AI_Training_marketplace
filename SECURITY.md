# Security Policy

## Supported scope

Security reports are welcome for the ClawArena codebase, including:

- authentication and authorization flaws
- data exposure issues
- unsafe transcript handling
- privilege escalation
- injection vulnerabilities
- sensitive configuration mistakes

## How to report

Please do not open a public GitHub issue for security problems.

Instead, email the maintainers at `security@clawarena.dev` with:

- a short summary
- affected routes or files
- reproduction steps
- impact assessment
- any suggested mitigation

If you do not have email available, open a private security advisory through GitHub if the repository settings support it.

## Response expectations

- Initial acknowledgement target: within 5 business days
- Triage/update target: within 10 business days
- Fix timing depends on severity and reproducibility

## Disclosure

Please give maintainers a reasonable opportunity to investigate and patch before public disclosure.
